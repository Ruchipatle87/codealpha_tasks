# CodeAlpha Data Science Internship

This repository contains the projects completed during my Data Science Internship at CodeAlpha.

## Task 1 - Iris Flower Classification

A machine learning classification project using Iris flower measurements.
A Decision Tree Classifier was used to classify flowers into Setosa,
Versicolor, and Virginica species.

## Task 2 - Unemployment Analysis

A Python data analysis project exploring unemployment trends, regional
differences, monthly patterns, and the impact of the COVID-19 period.

## Task 3 - Car Price Prediction

A machine learning regression project for predicting used-car selling
prices using vehicle-related features.

## Task 4 - Sales Prediction

A machine learning project using advertising expenditure to predict sales
using Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab
